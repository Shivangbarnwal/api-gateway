# API Gateway

A production-inspired API Gateway built from scratch using Node.js (without Express).

## Features

- Reverse Proxy
- Dynamic Routing
- Service Registry
- Round Robin Load Balancing
- Random Load Balancing
- Least Connections Load Balancing
- Health Checking
- Metrics Endpoint
- Rate Limiting
- Authentication & Authorization
- Admin API
- YAML-based Configuration
- Middleware Pipeline

## Tech Stack

- Node.js
- Native HTTP module
- YAML
